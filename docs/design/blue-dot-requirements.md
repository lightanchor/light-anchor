# 轻锚 · 蓝点 UI 最终需求（视觉验收基准）

> **唯一视觉基准：`blue-dot-mockup.html`（本目录，V7.5 最终版）**
> 浏览器打开可交互：顶部控制条切浅色/深色、切「现在」页有工作/空状态；
> URL 参数单看样张：`?page=later|waiting`、`?now=empty`、`?theme=dark`、
> `?focus=capture|settings|search|menubar`。
> **验收标准 = 实现与样机一模一样**（间距字号允许 ±10%，结构/颜色/层次不允许偏差）。

---

## 一、用户逐条明确过的硬性要求

1. **与样机 HTML 一模一样**——所有页面以样机为准，不按"差不多"验收。
2. **不要原生标题栏**——主窗标题栏完全透明 + 全尺寸内容，无灰条、无分隔线；
   红绿灯与右上工具按钮直接浮在暖米白上（已实现，保持）。
3. **捕获窗 = 悬浮写作条**（参考卡片流应用的浮动 composer）：
   - 无边框开放输入区，"写下现在想到的" + 闪烁蓝色光标；
   - 底部一排无描边小图标工具 + 「想法 ▾」类型 chip；
   - 右侧「取消」文字键 + **#5BA7CE 蓝底纸飞机发送键**；
   - 无窗口按钮（esc / 取消关闭）；整卡只靠大阴影悬浮。
4. **按钮用 #5BA7CE 蓝底白字**，不用黑色/墨色主按钮。
5. **无描边软填充控件**——所有按钮不允许有轮廓线（用户明确反感 outline）；
   次要按钮 = 米灰软填充，危险按钮 = 纯文字暖红。
6. **不要具象图形**（云朵/太阳/月亮/沙漏/对勾等）——状态一律用蓝点几何形态：
   实心+光环呼吸=进行中 / 空心环=暂停 / 虚线环=等待 / 双环=准备返回 / 灰点=结束；
   宜绿实心点=可以返回。
7. **黄历「宜」绿**用于"可以/就绪"语义：可返回组头+徽章、"定时提醒已触发"、成功态。
   徽章/点用本色 `#3E9B4F`，文字档 `#2E7D3C`（奶油底 4.8:1）。
8. **等待/搁置 = 暖黄徽章**（`#F6E3AE` 底 / `#8A6A14` 字），如侧栏「等待 2 项」。
9. **主题只有 自动(跟随系统)/浅色/深色** 三选；无暖色主题、无按时间切换。
10. **流程一条不改**——AttentionWorkspace/Domain/Services 与行为测试零改动；
    只换表现层。软件未发布，无向后兼容包袱。

## 三、布局结构（对照样机逐屏）

- **主窗**：宽侧栏 226pt（导航药丸行 + 弹簧蓝点指示 + 底部常驻当前状态：呼吸点+任务名+已持续 X 分钟）｜内容住在**奶油白圆角岛**（radius 14 + 发丝描边，四周留缝）。
- **首页（现在·有工作）**：居中白色 hero 卡——左上呼吸点状态行，右上**大号细体计时**（44pt ultraLight），26pt 标题，米灰现场条，渐隐发丝分隔，操作行（暂停=蓝主按钮 / 等待结果=米灰 / 结束这件事=暖红文字靠右）；卡下两枚统计胶囊居中。
- **首页空状态**（V7.6，用户否决同心圆环后定稿）：一枚放大的**呼吸蓝点**（14pt 点 + 光环缓慢扩散收拢，无任何装饰图形）+「先放一件事进来」+ 两按钮 + 灰色提示。
- **稍后**：读数行 + 软分段范围切换 + 行式列表（左：标题/「X 分钟前 · 类型」/蓝色建议语；右：操作按钮组），行间内缩发丝线。
- **等待**：组头（宜绿点/虚线点 + 彩字 + 同色徽章）+ 白卡行式列表；「暂时放下」行雾面 0.62；"定时提醒已触发"宜绿。
- **搜索（⌘F）**：居中浮层（背景压暗），大输入行 + esc 芯片，结果按目的地分组，悬停行 = 蓝水洗 + 左缘 2pt 蓝边条，底部快捷键提示条。
- **设置**：顶部药丸标签行（外观/接收/权限/智能/连接/数据）+ 分组白卡行式（左标题+说明、右控件），主题三张预览瓦片（选中蓝描边+蓝点标）。
- **菜单栏浮窗**：当前状态行 + 两个快捷按钮 + 宜绿"可以返回"/暖黄"暂时放下"/收件箱三行计数 + 打开工作区。
- **菜单栏图标**：蓝点形态即状态（实心=进行中/空心环=空闲/虚线环=等待）。

## 四、动效（硬上限 5 处，reduceMotion 全静态）

① 侧栏蓝点弹簧滑动 ② 状态点光环呼吸 ③ 空状态外环缓旋 ④ 现场舱推拉 ⑤ 捕获保存微弹/光标闪烁
