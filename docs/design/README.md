# 设计基准（冻结，不再更新）

这个目录里的两个文件是轻锚界面重建时定下的视觉基准，**已经冻结：不再更新，也不接受随实现变化的同步修改**。

| 文件 | 是什么 |
| --- | --- |
| [`blue-dot-requirements.md`](./blue-dot-requirements.md) | 用户逐条明确过的硬性要求、配色令牌、逐屏布局、动效上限 |
| [`blue-dot-mockup.html`](./blue-dot-mockup.html) | 对应的可交互样机（浏览器直接打开；`?page=later\|waiting`、`?theme=dark` 等参数可单看样张） |

## 为什么冻结

它们记录的是**当时定稿的那一版**，价值在于"当初是怎么定的、为什么这么定"。一份会跟着代码走的设计稿既不是需求也不是实现，两头都不可信；把它钉死在定稿那一刻，它才还能当基准用。

所以：

- **不要**因为实现变了就回来改这两个文件，也不要在这里补新功能的设计；
- 界面的当前事实以代码为准（`Sources/LightAnchor/Design/`、`Sources/LightAnchor/Views/`）;
- 实现与这里对不上时，先判断是实现跑偏了还是这版基准被有意推翻了——前者改实现，后者在别处记录新决定，两种情况都不改这两个文件；
- 将来若要做新一轮界面定稿，新开文件、新起版本，把这一版留在原地。
