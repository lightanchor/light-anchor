**你负责做事，它负责记得你做到哪儿了。**

写到一半被消息叫走，一件事卡在别人手里先去干别的——回来时，开着哪几个文件、下一步干什么，全得重新想。轻锚管的就是「切出去」这段时间：切走前自动记下现场，回来时原样交还。

没有账号，没有云端，也没有第 N 个待办清单——所有记录只在你自己的 Mac 上。
